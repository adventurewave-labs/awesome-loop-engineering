# Contributing

- One link per PR, alphabetical within its section.
- Format: `[name](url) - Why it matters for loop engineering (one line).`
- Must be loop-relevant: patterns, runners, memory/state strategies, stop conditions, safety, or economics of agent loops. General AI tools belong in other lists.
- No marketing pages, no dead links, no self-promotion without substance (working code or a real writeup).
- New sections need 3+ entries to justify themselves.
